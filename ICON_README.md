# Hisab app icon

| File | Size | Used for |
|---|---|---|
| assets/icon/icon.png | 1024×1024, no transparency | iOS + older Android; master for all sizes |
| assets/icon/icon_foreground.png | 1024×1024, transparent | Android adaptive icon foreground (inside 66% safe zone) |
| assets/icon/icon_monochrome.png | 1024×1024, transparent, white | Android 13+ themed icons |
| assets/icon/play_store_512.png | 512×512 | Google Play Store listing (upload manually) |

Background colour of the adaptive icon: #2D46B9 (primary in DESIGN.md).
All other sizes (mipmap-mdpi … xxxhdpi, iOS AppIcon set) are generated by `flutter_launcher_icons`.
Do not edit the generated files by hand; change the masters and run the generator again.
